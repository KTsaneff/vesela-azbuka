# Весела азбука (уеб версия, само българска азбука)

Игра за учене на българската азбука, направена за сина на собственика (3,5 г., октомври 2026). Цел: 10–15 минути на ден, да се усеща като игра, всичко на български.

- **На живо:** https://ktsaneff.github.io/vesela-azbuka/ (GitHub Pages, клон `main`, папка `/` root)
- **Сестринско репо:** [happy-alphabet-app](https://github.com/KTsaneff/happy-alphabet-app) — двуезична версия (БГ + EN) с Android приложение. Работи се по него в отделна сесия; тук не внасяй английски или Android.

## Принципи

- **Без сървър, без билд, без зависимости.** Статични файлове; всичко живее в `index.html`. Единствената външна заявка са Google Fonts (Rubik + Nunito, кирилица).
- **Само в браузъра.** Напредъкът е в `localStorage`, ключ `vesela-azbuka`. Всеки посетител има собствен напредък; нищо не се изпраща никъде. Всяко четене/писане е в `try/catch`.
- **За 3–4-годишно дете:** огромни бутони, без текст, който детето трябва да чете, за да играе; Таралежко (🦔) води и говори.
- **Целево устройство:** лаптоп/телевизор (клавиатура + мишка) и Android таблет. Работи и на телефон.
- Интерфейсът и commit съобщенията са на **български**.

## Файлове

| Файл | Какво |
| --- | --- |
| `index.html` | Цялата игра: CSS, разметка, JS (един IIFE) |
| `sw.js` | Service worker: stale-while-revalidate — веднага от кеша, обновяване на заден план. Кеш `azbuka-v2` |
| `manifest.webmanifest` | PWA: „Добавяне към началния екран“, fullscreen, landscape |
| `icon-192.png`, `icon-512.png`, `apple-touch-icon.png` | Иконки (червено „А“ на небе и трева) |
| `.nojekyll` | Да не минава през Jekyll |

## Как е устроена играта (`index.html`)

- **Данни:** масив `L` — по ред на буква `[главна, малка, ДУМА, картинка, име за гласа]`. Картинките са емоджи; за Щ има ръчно нарисуван SVG щъркел (`STORK`), а за И — игла (`🪡`). Ъ → ЪГЪЛ, Ь → ШОФЬОР (с пояснение, че Ь не започва думи; индекси 26 и 27 са изключени от дразнителите).
- **Сцени** (`section.scene`, превключване със `show(id)`): `home`, `learn` (буква пада → картинка → думата се изписва; звезда), `find` (намери буквата от 3), `pic` (коя картинка започва с буквата), `balloons` (спукай 5 балона с целевата буква).
- **Награди:** звезда за верен отговор; на всеки 5 звезди — стикер в албума (на началния екран се виждат **последните 8**, бутонът отваря целия албум: 24-те стикера, заключените като „?“, повторените с „×2“, а при натискане Таралежко казва името); след всичките 30 букви в „Буквите“ — **диплома** с име на детето, дата и печат.
- **Състояние `S`:** `stars, stickers, set` (избраните букви за деня, по подразбиране А–Е), `seen` (научени), `voice, sfx, name, dipDate`.
- **Родителски панел (⚙️):** избор на букви, глас, ефекти, преглед на дипломата, нулиране (с потвърждение в самата страница — `confirm()` не се ползва).
- **Звук:** ефекти с Web Audio (без аудио файлове); говор с Web Speech API само ако има `bg` глас (Edge има; Chrome на Android — след инсталиране на гласови данни; iPad — обикновено няма).
- **Клавиши:** Space/Enter/→ напред, ← назад, 1–4 избор, Esc начало, F цял екран.
- Уважава `prefers-reduced-motion`.

## Публикуване

`git push` в `main` → GitHub Pages обновява след ~1 мин. Заради stale-while-revalidate потребителите виждат новата версия **при второто отваряне**. При промяна на логиката в `sw.js` вдигни името на кеша (`azbuka-v3` …).

Трафик: GitHub Pages има мек лимит 100 GB/месец; страницата е ~55 KB, така че капацитетът е много голям.

## Проверка преди push

Няма тестове. Минимум: отвори `index.html` локално (или `npx serve .`), мини през четирите игри и родителския панел, провери конзолата за грешки и ширина ~400 px без хоризонтален скрол.
